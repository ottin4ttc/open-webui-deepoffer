# DeepOffer 页面改版方案

## 一、项目概述

### 1.1 改版目标
基于 Open-WebUI 改造为专用的 DeepOffer 大模型聊天服务，提供简洁、专业的用户体验。

### 1.2 核心改动
1. **简化用户功能**：通过后台配置限制模型选择，隐藏不必要的功能选项
2. **品牌定制**：将页面元素改造为 DeepOffer 品牌设计
3. **权限控制**：限制普通用户的配置选项

## 二、功能改造方案

### 2.1 权限配置

#### 修改默认权限
```javascript
const defaultPermissions = {
    workspace: {
        models: false,      // 禁用模型管理
        knowledge: false,   // 禁用知识库管理
        prompts: false,     // 禁用提示词管理
        tools: false        // 禁用工具管理
    },
    chat: {
        controls: false,    // 禁用控制面板
        file_upload: false,  // 禁用文件上传
        delete: true,
        edit: true,
        share: false,       // 禁用分享功能
        export: true,
        stt: false,         // 禁用语音输入
        tts: false,         // 禁用语音合成
        call: false,        // 禁用通话功能
        multiple_models: false,  // 禁用多模型
        temporary: true
    },
    features: {
        direct_tool_servers: false,
        web_search: false,   // 禁用网页搜索
        image_generation: false,  // 禁用图片生成
        code_interpreter: true,
        notes: false         // 禁用笔记功能
    }
};
```

### 2.2 界面简化

#### 需要隐藏的功能模块
1. **侧边栏**
   - 移除"工作区"入口
   - 移除"笔记"功能
   - 移除"游乐场"功能
   - 保留聊天历史和设置

2. **聊天界面**
   - 移除语音输入按钮（麦克风图标）
   - 移除电话/通话按钮
   - 移除文件上传功能（截图、上传文件等）
   - 移除消息朗读功能（扬声器图标）
   - 移除右上角菜单按钮（三个点）
   - 移除右上角控制面板按钮（Controls）
   - 简化设置选项
   - 移除高级功能入口

3. **设置页面**
   - 仅保留基础设置：
     - 通用设置（仅保留主题和语言选项，移除通知、系统提示词、高级参数等）
     - 账号管理（保留完整功能）
   - 移除以下菜单项：
     - 搜索功能
     - 界面设置（UI自定义）
     - 个性化设置
     - 语音设置
     - 对话设置
     - 关于页面
   - 移除的具体功能：
     - 工具配置
     - 高级选项
     - 界面自定义（宽屏模式、通知显示等）
     - 个性化选项（对话样式、标题生成等）
     - 语音相关所有设置
     - 系统信息展示

## 四、技术实现细节

### 4.1 模型配置

#### 管理员后台配置
1. 登录管理员账号
2. 进入模型管理界面
3. 配置 DeepOffer 模型 API
4. 在用户权限设置中限制可用模型列表
5. 确保普通用户只能访问 DeepOffer 模型

### 4.2 前端改造清单

#### 核心文件修改
1. **布局文件**
   - `src/routes/+layout.svelte` - 初始化配置
   - `src/routes/(app)/+layout.svelte` - 应用布局
   - `src/lib/components/layout/Sidebar.svelte` - 侧边栏

2. **聊天组件**
   - `src/lib/components/chat/Chat.svelte` - 主聊天界面
   - `src/lib/components/chat/SettingsModal.svelte` - 设置弹窗

3. **配置文件**
   - `src/lib/stores/index.ts` - 全局状态
   - `src/lib/constants.ts` - 常量定义

### 4.3 功能屏蔽方法

#### 条件渲染示例
```svelte
{#if $user?.role === 'admin'}
    <!-- 仅管理员可见的功能 -->
{/if}

{#if false}
    <!-- 完全隐藏的功能 -->
    <ModelSelector />
{/if}
```

#### 功能禁用实现
在 `src/lib/components/chat/MessageInput.svelte` 中：
- 语音输入按钮（第 1191-1237 行）受 `$_user?.permissions?.chat?.stt` 控制
- 电话/通话按钮（第 1264-1325 行）受 `$_user?.permissions?.chat?.call` 控制
- 文件上传功能受 `$_user?.permissions?.chat?.file_upload` 控制

在 `src/lib/components/chat/MessageInput/InputMenu.svelte` 中：
- 截图、上传文件等菜单项也受相应权限控制

在 `src/lib/components/chat/Messages/ResponseMessage.svelte` 中：
- 消息朗读按钮（第 1019-1030 行）受 `$_user?.permissions?.chat?.tts` 控制

在 `src/lib/components/chat/Navbar.svelte` 中：
- 三点菜单按钮（第 89-121 行）- 可通过隐藏或权限控制
- Controls 按钮（第 124-136 行）- 可通过 `controls` 权限控制

在 `src/lib/components/chat/SettingsModal.svelte` 中：
- 设置界面的tab列表定义（第 32-260 行）
- 搜索框实现（第 410-420 行）
- 各个tab的条件渲染（第 423-681 行）

注：设置界面需要通过修改组件代码来隐藏不需要的菜单项

通用设置页面简化（`General.svelte`）：
- 保留：主题选择（第241-258行）、语言选择（第260-288行）
- 移除：通知设置（第290-308行）、系统提示词、高级参数设置等

// 检查用户权限
